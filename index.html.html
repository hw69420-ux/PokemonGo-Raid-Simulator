Real observed combat logs show the attacker's first action never lands earlier than 1.5s in (vs. the boss's first action, which can land as early as 0.5s) — that 1.5s startup delay is removed in this simulator by request, so the attacker's first action now fires immediately at raid start instead.

Formula: DMG = ⌊0.5 × Power × (ATK/DEF) × STAB(1.2) × Effectiveness × Weather(1.2) × Friendship⌋ + 1 · No dodging assumed for any attacker, matching Pokebattler's "No Dodging" attack strategy · Multiplayer scales the team's damage against the boss.
Matches current raid mechanics: the boss gains energy equal to 50% of damage taken (rounded up) — this is boss-specific, not something the attacker's own Pokémon gets — and the boss rolls to fire its charged move each time it has enough energy, evaluated instantly (Niantic made firing 100% guaranteed on 7 Sept 2024, then set it to 30% — not back to 50% as widely assumed — on 12 Sept 2024, confirmed via a community-maintained config-history datamine; unlike the old pre-2024 system, which planned one turn ahead and couldn't queue two charge moves back-to-back, the current system can fire charge moves consecutively if energy allows, gated only by that roll each time). 30% is the default under "Boss Charge Move Chance" as a result — this session's independent testing against real combat logs had already converged on the same value before this source was found. Real logs show the attacker's own first action never lands earlier than 1.5s in, but that startup delay is removed in this simulator by request. Combat resolves in discrete 0.5-second ticks, also confirmed by the same datamine (matches every real log timestamp checked this session).
Every Pokémon is simulated 200 times (Monte Carlo) against the boss — figures below are averages across those 200 runs, using each Pokémon's first available fast + charged move. Estimator = players needed to defeat the boss within the raid's real 5-minute time limit, derived from the same 200-run average DPS.
Base stats, types & movepools: live from raw.githubusercontent.com/pvpoke/pvpoke (community-maintained GameMaster). Move names, power/energy and real animation duration: live from DialgaDex (javi-b/pokemon-resources on GitHub, sourced directly from the PokeMiners Game Master dump). The offline fallback database's movesets are hand-curated and may not be 100% legal/optimal for every entry — live data is authoritative.
